# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## What this is

OSEMN-style data pipeline (the *Obtain & Scrub* phase) that consolidates 10 years (2016–2025) of Chilean education data — SIMCE test scores and IDPS personal/social development indicators — into one analytical dataset for a linear-regression model predicting SIMCE from IDPS. The codebase is **Spanish**: comments, docs, commit messages, and column names. Match that language when editing docs or commits.

## Setup & commands

```bash
python3 -m venv venv && source venv/bin/activate && pip install -r requirements.txt
```

There is no test suite, linter, or build step — "running" means executing the ETL scripts.

Pipeline — two independent ETL scripts each produce one consolidated dataset, then a join script merges them into the analytical master:

```bash
python src/scrub_and_merge_idps.py    # -> data/processed/dataset_consolidado_idps.csv
python src/fusion_simce.py            # -> data/processed/dataset_simce_consolidado.csv
python src/build_dataset_maestro.py   # -> data/processed/dataset_maestro.csv (join PREDICTIVO, lag T-1)
python src/build_dataset_historico.py # -> data/processed/dataset_historico_completo.csv (join CONTEMPORÁNEO, todos los cursos)
python src/build_dataset_historico_per_curso.py # -> data/processed/por_curso/dataset_historico_{4b,6b,8b,2m}.csv (mismo join CONTEMPORÁNEO, un CSV por curso)
```

There are **three join scripts**, one per modeling approach (see Architecture): `build_dataset_maestro.py` (predictive, T-1 lag), `build_dataset_historico.py` (contemporaneous, same-year, all cursos in one file) and `build_dataset_historico_per_curso.py` (same contemporaneous join, split into one file per curso). All resolve paths from `__file__`, so they run from any working directory. `build_dataset_historico_per_curso.py` **imports** the normalization helpers from `build_dataset_historico.py` (import-safe thanks to its `__main__` guard).

Supporting scripts (not part of the SIMCE↔IDPS pipeline):

```bash
python src/extract_glossaries.py        # data/glosa*/**.xlsx -> data/processed/todas_las_glosas*.csv
                                        # NOTE: uses paths relative to CWD — run from the repo root, not via __file__.
python src/extraccion_presentacion.py   # ORPHANED: reads docs/presentacion.pdf (since removed). Needs pdfplumber.
```

## Critical: data layout

The ETL scripts read their source files directly from **`data/agrupado/`** (`idps/<curso>/` with per-grade subdirs `2m/4b/6b/8b`; `simce/` flat) — this is the committed, canonical source, so the pipeline runs on a fresh clone with no manual setup. (`data/raw/` was a redundant manually-copied mirror that the old scripts read from; it has been removed and the input paths now point at `data/agrupado/`. The `.gitignore` `data/raw/` line is now vestigial.)

- `data/processed/` — pipeline outputs, committed (the `!data/processed/` exception in `.gitignore`).
- `data/glosas_idps/`, `data/glosa_simce/` — official `.xlsx` variable dictionaries; read **only** by `extract_glossaries.py` (to build `todas_las_glosas*.csv`), not by the SIMCE/IDPS ETL.
- `data/processed/dataset_maestro.csv` — the **predictive** analytical master generated by `build_dataset_maestro.py`; input of the predictive modeling script (see Architecture/Notebook contract).
- `data/processed/dataset_historico_completo.csv` — the **contemporaneous** analytical master generated by `build_dataset_historico.py` (all cursos, same-year); input of the descriptive models (`datascienceproyecto1.py`, `ridge_simce_modelo_unificado.py`). See [docs/diccionario_historico_completo.md](diccionario_historico_completo.md).
- `data/processed/por_curso/dataset_historico_{4b,6b,8b,2m}.csv` — the **per-curso** contemporaneous datasets generated by `build_dataset_historico_per_curso.py`; same schema as `dataset_historico_completo.csv` but one file per grade (their rows are exactly the per-curso slices of the complete dataset). Input of the per-curso modeling script `datascienceproyecto1_per_curso.py`. Rows: 4b≈39.7k, 2m≈20.6k, 6b≈19.8k, 8b≈17.7k.
- `data/dataset_historico_final.csv` **and `data/processed/dataset_analitico.csv`** — committed but **no current script generates them**; legacy/frozen artifacts. `dataset_historico_final.csv` was the *old* Colab notebook's input (only 2m, 2017–2023) — superseded by `dataset_historico_completo.csv` (all cursos). Note it now lives in `data/`, not `data/processed/`.

## Architecture

Two independent raw sources are each consolidated into a wide per-`(rbd, agno, curso)` dataset:

1. **`scrub_and_merge_idps.py`** — pure **Obtain** phase (no filtering, no dropna, no imputation — those are Scrub, done later on this output). Reads only the *main* index file per `(curso, año)` (excludes `*_dim_*`, `*niveles*`, `*subdim*`), takes `curso` from the subdir name (the `grado` column is truncated/inconsistent), pivots both long variants — `ind` text AM/CC/HV/PF (2022–2024) and `id_indicador` codes 1–4 (2025, where **1=AM, 2=CC, 3=HV, 4=PF**) — to wide, then applies a fixed 20-column whitelist (`OUTPUT_COLUMNS`) so name variants/garbage are dropped. Output: one row per `(rbd, agno, curso)`, all cursos/years 2016–2025, columns `idps_am/cc/hv/pf` + context.
2. **`fusion_simce.py`** — globs `*_rbd*` files only (establishment level), detects the delimiter with an explicit `infer_separator()` (pipe for 2016–2022, `;` for 2023+; `sep=None`/`csv.Sniffer` used to fail on pipe and silently drop those years), regex-normalizes the grade-suffixed score columns (`prom_mate2m_rbd` → `prom_mate_rbd`), infers `curso`/`agno` from filename when absent, then **drops any row missing either target** (`prom_mate_rbd`/`prom_lect_rbd` — this dropna is a Scrub step still living inside Obtain). Covers all years 2016–2025.

3. **`build_dataset_maestro.py`** — the **join stage** (restored, replacing the old removed `build_analytical_dataset.py`). It merges the two consolidated outputs into the **predictive master** `data/processed/dataset_maestro.csv` with a **one-year temporal lag**: it shifts each source's `agno` by +1 and inner-joins `IDPS(T-1)`, `SIMCE(T-1)` and `SIMCE(T)` on `(rbd, agno, curso)`, so features are measured at T-1 and the SIMCE target at T (this is the *predictive* fix the professor asked for; the old contemporaneous join was the weakness). It ordinal-encodes NSE (`nse_ord` 1–5, normalizing the mixed numeric/text `cod_grupo` present in **both** sources), adds `curso_ord` (4b=4…2m=10), and keeps prior-year SIMCE (`simce_*_prev`) as autoregressive predictors. **No imputation/scaling/outlier removal** (those live in the notebook pipeline to avoid leakage). See [docs/diccionario_maestro.md](diccionario_maestro.md). **The inner join on consecutive years means only annually-tested grades survive: `4b` and `2m`** — `6b`/`8b` are tested in alternating years (no consecutive pairs) and drop out. Output: ~39.9k rows, target years 2017,2018,2023,2024,2025.

The historical context: a former `build_analytical_dataset.py` did a *contemporaneous* `(rbd, agno)` inner-join filtered to II Medio and emitted the 11-column `dataset_historico_final.csv` the **old** Colab notebook consumed; it was removed in commit `c1d8154` and is now superseded by `build_dataset_maestro.py`. `dataset_historico_final.csv` and `dataset_analitico.csv` remain committed but **frozen** (no script regenerates them); treat as legacy artifacts.

`extract_glossaries.py` is a standalone reference utility (unrelated to the join): it scans the `.xlsx` dictionaries in `data/glosa_simce/` + `data/glosas_idps/`, skipping index/metadata sheets, and writes consolidated `todas_las_glosas{,_simce,_idps}.csv` to `data/processed/`.

The hard problems this pipeline exists to solve are year-over-year **data drift** (documented in `docs/diccionario_idps.md` / `docs/diccionario_simce.md`): shifting delimiters, wide→long restructuring in 2023, column-name casing/variants, `latin1` vs `utf-8-sig` encoding, grade suffix embedded in score column names, and truncated `curso` codes (`'2'`→`'2m'`, handled by `CURSO_NORMALIZE` in `scrub_and_merge_idps.py`). IDPS is consolidated with `groupby(...).mean()` specifically so that any un-pivoted 2023+ long rows still collapse correctly. When touching the ETL, consult these dictionaries first — they are the authoritative record of per-year structural exceptions.

## Modeling scripts

There are **two modeling lines**, each fed by its own join script. Both are plain `.py` (originally Colab exports), run locally (no Colab), and load their dataset via an upward path search (`encontrar_dataset()`, runs from repo root or `src/`).

**Contemporaneous / descriptive (teammates'):**
- `src/datascienceproyecto1.py` — multiple linear regression, **two models** (`prom_mate2m_rbd`, `prom_lect2m_rbd`). Adapted to: read `data/processed/dataset_historico_completo.csv` locally, include `curso` in `features_cat` (so all 4 cursos are distinguished), and **save plots to `reports/figuras_regresion_lineal/`** instead of `plt.show()` (uses `matplotlib.use("Agg")` + a `guardar()` helper). Same-year association study (the prof flagged same-year framing as a weakness, but the team keeps a descriptive line on purpose).
- `src/ridge_simce_modelo_unificado.py` — Ridge, mate+lect unified in long format via `melt`, with `tipo_prueba`. **Still Colab-style / not yet adapted** (uses `files.upload()` + `display()`); on standby — when adapting, mirror the three changes above and carry `curso` through the `melt` `id_vars`.
- `src/datascienceproyecto1_per_curso.py` — **per-curso variant** of the descriptive line: instead of one pair of models over all cursos mixed, it fits one mate+lect pair **per curso** (4b/6b/8b/2m → 8 models) to study how the IDPS effect changes by educational level. Reads the `data/processed/por_curso/` files. Key methodological difference: the **IQR outlier trim is computed per curso** (over homogeneous rows), and `curso`/`nse_x_curso` are dropped (constant within a curso). Self-contained: it **duplicates** the helpers from `datascienceproyecto1.py` (that module runs its whole analysis at import time, so it is not importable without side effects). Saves ~18 PNG to `reports/figuras_por_curso/` and prints per-curso skew/VIF/Train-vs-Test/Cook tables plus a cross-curso coefficient summary and an evolution plot. Verified test R²: heterogeneous (2m≈0.60 highest, 4b≈0.35 lowest).

**Predictive (yours):** *(script `src/modelo_predictivo_simce.py` was deleted by the user; the predictive dataset `dataset_maestro.csv` and its `build_dataset_maestro.py` remain.)* If rebuilt, it consumed `dataset_maestro.csv` with ordinal NSE/curso, Pearson + VIF, two separate models, out-of-time split (train 2017/2018/2023/2024, test 2025), Train-vs-Test MAE/RMSE/R², residuals and Cook's distance; verified test R²≈0.62 (mate)/0.52 (lect).
